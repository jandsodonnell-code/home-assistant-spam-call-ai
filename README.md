# Home Assistant Spam Call AI

AI spam-call screening for Home Assistant using Twilio and OpenAI GPT-Live.

## Add this repository to Home Assistant

In Home Assistant:

1. Go to **Settings → Apps → Install app**
2. Open the **⋮** menu → **Repositories**
3. Add:

   https://github.com/jandsodonnell-code/home-assistant-spam-call-ai

4. Refresh the Apps store
5. Install **Spam Call AI**

After installation, open the app's **Configuration** tab and enter your own
OpenAI and Twilio credentials. Do not share those secrets in screenshots or chat.

See `spam_call_ai/DOCS.md` for setup details.
